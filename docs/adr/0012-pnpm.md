# 0012. pnpm as the package manager

Status: accepted (supersedes the npm workspaces setup)

## Decision
pnpm 10 with `pnpm-workspace.yaml`, `workspace:*` for internal dependencies and a committed `pnpm-lock.yaml`. CI uses `pnpm install --frozen-lockfile`.

## Why
Strict dependency resolution makes an undeclared import fail, which backs the module-boundary rule; installs are faster and share one store.

## Consequences
- Each package declares what it imports. Root tests and scripts import `pg`, `pg-boss`, `embedded-postgres` and OpenTelemetry packages, so the root declares them as devDependencies.
- Install scripts are blocked unless listed in `onlyBuiltDependencies` (embedded-postgres, esbuild).
- `@opentelemetry/api` is pinned to ~1.9 because the 1.x SDK packages need `<1.10`.
- On a slow mounted checkout, set `store-dir` to a local disk.
